# Code-Helper-Elma

Code Helper Elma is a lightweight tool that maps code snippets directly to their corresponding mathematical formulas and algorithms in PDFs.

The name comes from the lovely character Elma from the anime [Miss Kobayashi's Dragon Maid](https://zh.wikipedia.org/zh-tw/%E5%B0%8F%E6%9E%97%E5%AE%B6%E7%9A%84%E9%BE%8D%E5%A5%B3%E5%83%95).

## Installation

Clone this repo, and install the required dependency:

```
cd Code-Helper-Elma

pip install -r requirements.txt
```

## Usage

The buttons and the instructions should indicate the way to use it. Basically, click the right-most button to mark the algorithm (or anything on the PDF page) you refer to. After you click the button, select the code snippets first, and press Ctrl+C. This allows the code snippets to be recorded. Then, mark the reference with a box on the PDF page. Press the (now turned) green button, and confirm the mapping. Done.

<br>

To view the mapping, select the target code snippets and press Ctrl+C. The corresponding marks will show up in the PDF viewer.

<br>

The PDF files should be placed in the 'pdf' directory under the application directory.

<br>

Unfortunately, the buttons and instructions are (for now) in Chinese. Contributions to the English version of the program is highly welcome.
